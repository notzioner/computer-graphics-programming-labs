# Activity 1: 2D Animation Principles & Kinematics Engine (Tweening & Morphing)

This activity uses Python and Pygame to create three different animations.

First, tweening was used to make a sprite move smoothly along different points using interpolation.

Second, polygon morphing was used to change a triangle into a rectangle by matching and moving their vertices.

Third, a bouncing ball was created using gravity, velocity, and restitution to make the movement look more realistic.

The program also includes keyboard controls:

1 – Tweening
2 – Morphing
3 – Bouncing Ball

The program runs at 60 FPS to keep the animations smooth.
