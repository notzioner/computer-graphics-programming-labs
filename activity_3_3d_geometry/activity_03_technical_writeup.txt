Activity 3: 3D Coordinate Geometry & Spatial Bounding Volumes (AABB/Sphere)

This activity uses Python and Pygame to create a simple 3D coordinate geometry and collision detection program.

First, 3D points were created using x, y, and z coordinates. The program calculates the distance between two points and performs vector operations such as subtraction, dot product, and cross product.

Second, bounding spheres and Axis-Aligned Bounding Boxes (AABB) were created to represent the boundaries of 3D objects.

Third, sphere and AABB collision detection were used to check if objects are intersecting. The program uses squared distances for sphere collisions to avoid unnecessary square root calculations.

The program also verifies the given examples:

Distance between P(2, -1, 7) and Q(1, -3, 5) = 3.0
Sphere center = (-2, 3, -1)
Sphere radius = √8 ≈ 2.828

Finally, 100 random 3D objects are generated and displayed in a Pygame window. Their bounding spheres and AABBs are shown visually, while detected collisions are highlighted.

The program also includes:

R – Regenerate 100 random objects
ESC – Quit the program

The program runs at 60 FPS to keep the visualization smooth.
