# Activity 2: Interactive Game Architecture: Game Loop & Sprite Collision

This activity uses Python and Pygame to create a simple interactive game.

First, a player sprite was created that can move using the arrow keys.

Second, obstacle sprites were added and programmed to move around the screen.

Third, collision detection was used to detect when the player hits an obstacle. The program also includes a score and health system.

The program also includes:

Arrow Keys – Move the Player
ESC – Quit the Game

The program uses sprite groups, collision detection, and translucent particles for visual effects. It also runs at 60 FPS to keep the game smooth.
