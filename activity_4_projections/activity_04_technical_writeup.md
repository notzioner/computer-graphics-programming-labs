# Activity 4: 3D Projection Engine: Orthographic, Oblique & Perspective

This activity uses Python and Pygame to create a 3D projection engine that displays a wireframe cube.

First, a 3D cube was created using vertices and edges. The cube can be rotated around the X, Y, and Z axes using keyboard controls.

Second, different projection methods were implemented to transform the 3D cube into a 2D display. These include Orthographic, Cavalier Oblique, Cabinet Oblique, and Perspective projection.

The program also allows switching between the four projection modes:

1 – Orthographic
2 – Cavalier Oblique
3 – Cabinet Oblique
4 – Perspective

The cube can be rotated using:

Arrow Keys – Rotate around X and Y axes
Q / E – Rotate around the Z axis
R – Reset the rotation
ESC – Quit the program

In Perspective mode, the cube demonstrates how lines appear to converge toward a vanishing point. The program runs at 60 FPS for smooth real-time rendering.
